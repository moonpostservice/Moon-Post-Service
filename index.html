The World's Only Moon Postal Service

Not every messageshould arrive immediately.

Some words deserve distance. Anticipation. A sky.

Moon Post Service is the world's only moon-based messaging platform.
Here is how it works: a message can be sent only when the moon is above you.
It does not arrive instantly. It travels, and is delivered only when the moon rises for the person you sent it to.

That waiting is part of the feeling.

Because some messages should not arrive like every other notification.
They should gather a little darkness around them.
A little time. A little longing.

◑

There was a time when sending something meant letting it go.
A letter crossed distance before it arrived.
That distance gave it weight.
Instant messaging erased much of that space between us.

Moon Post Service brings some of it back.
A small daily ritual.
A different way of staying close.

Messages live for one lunar cycle. Like moonlight, they're not meant to be stored — they're meant to be felt.
